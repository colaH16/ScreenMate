# 설계 결정

`CLAUDE_HANDOFF.md`의 확정 동작을 구현하면서 정한 세부 사항. 숫자 기준은 모두
`Packages/ScreenMateKit/Sources/ScreenMateCore`에 있고 단위 테스트로 고정되어 있다.

## 전송/엔진

- **엔진**: rootshell-vnc v0.1.8 (MIT)을 `Vendor/`에 고정. 공개 API 2개만 패치 (`Vendor/VENDOR.md`).
- **화질**: 기본 `Standard`(TCP, Apple adaptive). `High Performance`(HEVC/UDP)는 NetBird 등 터널에서
  불안정할 수 있고 렌더링 경로가 달라 1차 범위에서 뺐다. 프로필별로 `무손실`(Full Quality) 선택 가능.
- **해상도**: `remoteDisplay` 고정. 아이폰 크기의 가상 디스플레이를 Mac에 만들지 않는다
  (Mac의 실제 모니터 배치를 바꾸지 않음).
- **인증**: 보안 정책 `automatic`. 이 Mac은 2026-11-01 기준 `RFB 003.889`, 보안 타입
  `[30, 33, 36, 31, 32, 35]`을 제시했다(클래식 VNC 암호 타입 2 없음). 엔진이 Apple DH(30)/Mac 인증(33)/
  SRP(36)를 처리한다. 사용자 이름이 있으면 Mac 인증(33)을 고른다.
- **암호화(확인된 한계)**: 2026-11-01 실호스트 확인 결과 Standard 모드의 협상된 콘텐츠 암호화는 `none`이다.
  인증 교환(암호)은 보호되지만 화면과 키 입력(잠금 화면 암호 포함)은 RFB 계층에서 암호화되지 않는다.
  NetBird 경유는 WireGuard가 암호화하므로 문제가 없고, LAN 직접 접속만 평문이다. 엔진의
  `requireEncryption`은 Mac이 제공하지 않는 VeNCrypt만 허용하므로 그대로 켤 수 없다. Apple 방식 암호화
  (ComCryption)를 Standard 모드에서 협상할 수 있는지는 후속 과제.
- **잠금 화면**: `promptForLoginPasswordAtLoginWindow = false`. 저장된 암호를 Mac 잠금 화면에 자동
  입력하지 않는다. 연결 후 키보드로 직접 해제한다(VNC 인증과 OS 잠금 해제는 별개).
- **재연결**: 연결이 성립한 뒤 끊기면 최대 5회, 1s→15s 지수 백오프(엔진 기본 지터 포함). 그 뒤에는
  "다시 연결" 버튼. 수동 재시도를 위해 암호는 세션이 열려 있는 동안만 메모리에 둔다(인증 실패 시 폐기).
- **첫 연결 실패 시간**: 엔진이 VPN 온디맨드 대응으로 TCP 다이얼을 10초×3회 시도하므로, 닫힌
  포트·잘못된 주소는 실패 표시까지 최대 약 33초 걸린다. 연결 중 화면에 단계 표시와 취소 버튼을 둔다.
- **오류 구분**: 네트워크 / 인증 / 프로토콜 / 미지원 4종(`ConnectionFailure.classify`).
- **수동 새로고침**: 더보기 메뉴의 "화면 새로고침(복구용)". 정상 사용 흐름에는 필요 없다.

## 모니터

- **수신 방식**: 항상 모든 모니터를 결합한 데스크톱(`allDisplaysCombined`)을 받고, 모니터 1/2/전체는
  클라이언트에서 영역을 잘라 표시한다. 전환이 즉시이고 재연결이 없다. 대신 대역폭은 전체 데스크톱 기준이다.
- **번호**: Mac이 알린 순서(주 모니터가 먼저). 메뉴에 `모니터 2 · 오른쪽 · 3440×1440`처럼 위치를 같이 표시.
- **좌표**: 서버 좌표의 음수 원점(왼쪽/위 모니터)을 결합 데스크톱 원점으로 평행이동, 서버 좌표와
  프레임버퍼 단위가 다르면 축별 배율 보정(`MonitorLayout`).
- **자동 전환**: 기본 OFF. ON이면 포인터가 다른 모니터에 들어갈 때 그 모니터로 전환("전체"는 유지).
- **미결정 사항 — 자동 전환 OFF일 때 포인터 가두기: 기본 ON**. 트랙패드 방식에서는 포인터가 보여야
  쓸모가 있는데, 자동 전환이 꺼진 상태에서 보이지 않는 모니터로 포인터가 넘어가면 보이지 않는 곳을
  클릭하게 된다. 프로필 편집과 세션 모니터 메뉴에서 끌 수 있고, 끄면 화면은 선택한 모니터에 머물고
  "포인터가 모니터 N에 있습니다 · 보기" 안내가 뜬다.
- 모니터 사이 빈 공간(높이가 다른 모니터)에는 포인터가 머물지 않는다.

## 화면 이동(뷰포트)

- 기준 영역: 기기 크기가 아니라 앱 창에서 원격 화면이 실제로 보이는 영역(도구모음·키보드·안전영역 제외).
  회전, 키보드, iPad 창 크기 변경 시 `viewDidLayoutSubviews` → 재계산.
- 3×3 중앙 칸 안: 정지. 벗어나는 즉시 해당 축·방향으로 포인터와 같은 속도로 따라감(포인터는 중앙 칸
  경계에 머묾). 가장자리에서는 clamp, 포인터는 끝 픽셀까지 이동. 다 들어오는 축은 가운데 정렬·고정.
- "부드럽게": 연속 이동은 손가락과 같은 속도로 따라가므로 끊김이 없다. 모니터 전환·레이아웃 변경
  같은 불연속 이동만 0.22초 애니메이션.
- 확대: 1 = 전체가 보이는 맞춤 배율, 최대 2pt/px. 핀치는 포인터 기준으로 확대해 확대 후에도 포인터가
  중앙 칸에 남는다. 모니터를 바꿔도 맞춤 대비 확대 배율 유지.

## 입력

- **포인터**: 상대 이동(트랙패드). 손가락 이동 거리 × 감도(1.0) ÷ 확대율. 200pt/s 이하는 가속 없음,
  그 이상 최대 1.9배. 착지 위치는 무시.
- **탭** = 왼쪽 클릭, **두 번 탭** = 더블클릭, **탭 후 다시 눌러 끌기**(tap-and-a-half) = 드래그,
  **두 손가락 탭** = 오른쪽 클릭. 드래그를 위해 단일 탭 클릭은 0.25초 늦게 전송된다(macOS의 "두 번
  탭하여 드래그"와 같은 절충). 첫 클릭을 즉시 보내면 Mac이 드래그 시작을 더블클릭으로 해석한다
  (제목 막대 확대, 파일 열기).
- **두 손가락**: 처음 10pt 움직임으로 스크롤/핀치를 한 번 판정하고 제스처 끝까지 유지. 스크롤은
  상하좌우·대각선 동시, Apple 정밀 스크롤 이벤트(자연 스크롤 방향) + 휠 단위 누적. 확대 상태와 관계없이
  원격 내용이 손가락을 따라오도록 이득 `clamp(1/scale, 1, 4)`. 관성 스크롤은 1차 범위 밖.
- **viewport만 수동 이동하는 기능은 없음**(확정 사양).
- **보조키**: 도구모음 ⌃⌥⇧⌘는 다음 키 1회 또는 다음 클릭/드래그에 적용 후 해제.
- **iPad 외장 마우스/트랙패드**: 터치 제스처는 `direct` 터치만, 포인터 제스처는 `indirectPointer`만
  받아 같은 동작이 두 번 전송되지 않는다. iPad 자체 포인터는 숨기고 Mac 포인터만 그린다. 포인터 잠금이
  가능하면(전체 화면 앱) GameController 원시 델타로 화면 가장자리에서도 계속 이동, 아니면 hover 델타.
  클릭=왼쪽, 보조 클릭=오른쪽, 버튼 누른 채 이동=드래그, 트랙패드 스크롤/핀치는 터치와 같은 규칙.
- **하드웨어 키보드**: HID 키코드 → keysym, key-down/up 그대로 전달(Mac에서 키 반복). 키를 누른 동안
  modifier가 바뀌어도 key-up은 key-down과 같은 keysym. 포커스를 잃으면 눌린 키·버튼 모두 해제.

## 한글 입력 (지원 범위와 한계)

- **iOS 키보드 직접 입력**: ASCII 키보드만 띄운다. 각 키가 Mac에 키 이벤트로 가고, 결과는 Mac의 입력
  소스가 결정한다. Mac을 한글(두벌식)로 바꾸면(⌃Space 버튼) 영문 자판 위치로 한글이 입력된다 —
  물리 키보드와 같은 방식이지만 화면 자판에는 영문이 표시된다.
- **텍스트 보내기 → 붙여넣기**: iOS 한글 키보드로 조합한 텍스트를 Mac 클립보드에 넣고 ⌘V. 한글·이모지
  ·긴 글이 Mac 입력 소스와 관계없이 들어가지만 Mac 클립보드 내용을 덮어쓴다. 붙여넣기를 막는 입력란
  (일부 암호 입력란)에서는 안 된다.
- **iOS 한글 키보드로 실시간 직접 입력은 지원하지 않는다**: iOS IME 조합(자모 결합·수정)과 Mac IME
  조합이 이중으로 일어나 글자가 깨진다.
- iPad 하드웨어 키보드는 키코드 그대로 전달되므로 Mac 입력 소스가 한글이면 한글이 입력된다. 단 iPadOS가
  가로채는 키(⌘Tab, ⌘Space, 한/영 전환 키 일부)는 Mac에 가지 않는다 → 더보기 › Mac 단축키 메뉴 제공.
- 위 동작은 실기기에서 아직 검증하지 않았다.

## 저장

- 접속 목록: `Application Support/ScreenMate/profiles.json` (암호 없음, 파일 보호 complete).
- 암호: 사용자가 켠 경우에만 Keychain(`WhenUnlockedThisDeviceOnly`, 기기 이전·백업 제외).
- 첫 실행 시 `App/StarterProfiles.json`(git 제외, 형식은 `docs/StarterProfiles.example.json`)의 Mac들로
  목록을 채운다. 파일이 없으면 빈 목록에서 시작한다. 모두 편집·삭제 가능.
- 개인 값(주소, 사용자명, 서명 팀, 번들 ID 접두사)은 공개 저장소에 넣지 않는다:
  `App/StarterProfiles.json`, `Config/Signing.local.xcconfig`, `CLAUDE_HANDOFF.md`는 `.gitignore` 대상.
